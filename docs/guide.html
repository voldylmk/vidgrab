Le guide VidGrab

Télécharger une vidéo en quelques étapes.

← Retour à VidGrab

Avant de commencer

VidGrab fonctionne dans le navigateur, sur ordinateur comme sur téléphone. Aucune application à installer. Copie le lien d’une vidéo publique sur X, Instagram, Facebook ou TikTok, puis colle-le dans VidGrab.

Sur ordinateur

  1. Ouvre VidGrab dans ton navigateur.
  2. Copie le lien de la vidéo depuis la plateforme, puis clique sur Coller dans VidGrab. Tu peux aussi cliquer dans le champ et utiliser Ctrl + V (ou ⌘ + V sur Mac).
  3. Quand le lien apparaît, le bouton Coller est remplacé par le bouton ✕. Clique sur ✕ pour vider le champ et recommencer.
  4. Clique sur Analyser le lien pour voir l’aperçu et choisir la qualité. Si Télécharger directement, sans aperçu est activé, le bouton lance le téléchargement directement.
  5. Choisis Vidéo MP4 ou Audio MP3, puis la qualité souhaitée, et clique sur Télécharger.

Sur mobile

  1. Dans l’application où tu as trouvé la vidéo, touche Partager, puis Copier le lien.
  2. Ouvre VidGrab dans le navigateur de ton téléphone. Appuie sur Coller. Si le collage est bloqué, garde le doigt dans le champ et choisis Coller.
  3. Le bouton ✕ apparaît à côté du champ lorsque le lien est présent. Touche-le pour effacer le lien; le bouton Coller réapparaît.
  4. Touche Analyser le lien ou, si le téléchargement direct est activé, le bouton Télécharger.
  5. Choisis le format et la qualité si l’aperçu s’affiche, puis touche Télécharger. Le fichier se trouve ensuite dans les téléchargements du navigateur ou dans l’application Fichiers de ton téléphone.

Choisir le format

  • Vidéo MP4 : pour enregistrer l’image et le son. Sélectionne une qualité disponible jusqu’à 1080p.
  • Audio MP3 : pour enregistrer le son seulement. Sélectionne 128, 192 ou 320 kbps.

Si quelque chose ne fonctionne pas

  • Vérifie que le lien vient de X, Instagram, Facebook ou TikTok et qu’il est complet.
  • Si le serveur se réveille, patiente quelques secondes puis réessaie.
  • Si le téléchargement ne démarre pas, vérifie les téléchargements de ton navigateur et réessaie avec une autre qualité.
  • Certains contenus peuvent être indisponibles ou protégés par la plateforme.

Télécharge uniquement les contenus que tu as le droit d’enregistrer et respecte les droits des créateurs.
